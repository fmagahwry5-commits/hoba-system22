# نظام هوبا للإدارة والمبيعات 🧾

نظام إدارة ومبيعات كامل يعمل على **الكمبيوتر والموبايل معاً** — بوضعين للتشغيل:

- 🏠 **محلي**: الكمبيوتر سيرفر + الأجهزة تتصل عبر نفس الواي فاي (البيانات على جهازك)
- ☁️ **سحابي**: استضافة مجانية برابط خاص يعمل **من أي مكان في العالم** — انظر [DEPLOY.md](./DEPLOY.md)

## ✨ المميزات

- 📊 لوحة تحكم: مبيعات اليوم والشهر + صافي الربح
- 🧾 فواتير بيع مرتبطة بالمخزون تلقائياً + طباعة — آمنة ضد البيع المتزامن من جهازين
- 📷 **مسح باركود** بكاميرا الموبايل + قارئ USB + إضافة سريعة بالاسم
- 📦 إدارة المنتجات والمخزون مع تنبيه النواقص
- 👥 إدارة العملاء
- 💸 تسجيل المصروفات
- 🔐 **تسجيل دخول وصلاحيات**: مدير (كامل الصلاحيات) + كاشير (بيع وعرض فقط)
- 📈 **تقارير شهرية**: مبيعات، أرباح، أفضل المنتجات، مبيعات كل بائع + تصدير Excel (CSV)
- 📱 يتثبّت على الموبايل كتطبيق (PWA)
- 💾 نسخ احتياطي بضغطة زرار

---

## 🚀 التشغيل المحلي (على جهازك)

### 1. ثبّت Node.js (مرة واحدة فقط)
حمّله من <https://nodejs.org> — اختر نسخة **LTS**.

### 2. نزّل المشروع
```bash
git clone https://github.com/fmagahwry5-commits/hoba-system22.git
cd hoba-system22
git checkout arena/019f7c33-hoba-system22
```

### 3. شغّل النظام
```bash
node server.js
```
> ✅ لا يحتاج `npm install` — لا توجد أي مكتبات خارجية.

### 4. أنشئ حساب المدير
افتح **http://localhost:3000** ← ستظهر شاشة الإعداد الأولي ← أنشئ حساب المدير (مرة واحدة).

### 5. الربط بالموبايل (نفس الواي فاي)
عند التشغيل سيظهر عنوان مثل `http://192.168.1.5:3000` — افتحه من متصفح الموبايل وسجّل دخولك.
- **لتثبيته كتطبيق** ومسح الباركود بالكاميرا بشكل كامل يُفضَّل الوضع السحابي (HTTPS) — انظر [DEPLOY.md](./DEPLOY.md).
- لو الموبايل لم يفتح: تأكد من نفس الواي فاي + اسمح لـ Node.js في جدار حماية ويندوز.

## ☁️ الوضع السحابي (من أي مكان) — مجاني بالكامل

رفع النظام على **Vercel** (استضافة مجانية بدون بطاقة بنكية وبدون "نوم") مع قاعدة بيانات **Supabase** المجانية —
رابط واحد يفتح من أي جهاز وأي مكان، والبيانات مشتركة لحظياً.

📖 **الدليل الكامل خطوة بخطوة:** [DEPLOY.md](./DEPLOY.md) (~15 دقيقة)

## 🗂️ هيكل المشروع

```
hoba-system22/
├── server.js            # السيرفر المحلي (npm start)
├── handler.js           # معالج الـ API الموحّد (محلي + Vercel)
├── api/index.js         # نقطة دخول Vercel (Serverless)
├── vercel.json          # توجيه /api/* للدالة
├── auth.js              # تشفير كلمات المرور + توكنات جلسات موقّعة
├── store.js             # اختيار التخزين تلقائياً (محلي/سحابي)
├── store-json.js        # التخزين المحلي (data/db.json)
├── store-supabase.js    # التخزين السحابي (Supabase عبر REST)
├── supabase-setup.sql   # إعداد القاعدة السحابية (يُلصق مرة واحدة)
├── public/              # الواجهة: صفحات، تصميم، PWA
├── tests/               # اختبارات آلية (node tests/<file>)
├── DEPLOY.md            # دليل النشر المجاني
└── data/db.json         # البيانات المحلية (تُنشأ تلقائياً — لا تُرفع على GitHub)
```

## ⚙️ متغيرات البيئة

| المتغير | الغرض | افتراضي |
|---------|-------|---------|
| `PORT` | منفذ التشغيل المحلي | `3000` |
| `SUPABASE_URL` | رابط مشروع Supabase | *(غير مضبوط = وضع محلي)* |
| `SUPABASE_SERVICE_KEY` | مفتاح service_role (سري — على السيرفر فقط) | *(غير مضبوط = وضع محلي)* |
| `SESSION_SECRET` | سر توقيع توكنات الجلسات — **إلزامي على Vercel** | *(عشوائي كل تشغيل محلياً)* |

## 💾 النسخ الاحتياطي

- محلياً: انسخ ملف `data/db.json` — أو من **الإعدادات ← تنزيل نسخة احتياطية**.
- سحابياً: نفس الزر داخل النظام ينزّل كل شيء كملف JSON.
