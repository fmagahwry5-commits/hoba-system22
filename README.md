# نظام هوبا للإدارة والمبيعات 🧾

نظام إدارة ومبيعات بسيط يعمل على **الكمبيوتر والموبايل معاً** من خلال المتصفح —
الكمبيوتر هو "السيرفر" الذي يحفظ البيانات، والموبايل يتصل به عبر الواي فاي.

## ✨ المميزات

- 📊 لوحة تحكم: مبيعات اليوم والشهر + صافي الربح بعد المصروفات
- 🧾 فواتير بيع مع خصم تلقائي من المخزون + طباعة
- 📦 إدارة المنتجات والمخزون (مع تنبيه النواقص)
- 👥 إدارة العملاء
- 💸 تسجيل المصروفات
- 📱 يتثبّت على الموبايل كأنه تطبيق (PWA)
- 💾 كل البيانات محفوظة على جهازك في `data/db.json`

---

## 🚀 التشغيل على الكمبيوتر

### 1. ثبّت Node.js (مرة واحدة فقط)
حمّله من الموقع الرسمي: <https://nodejs.org> — اختر نسخة **LTS** وثبّتها بالضغط على "Next" حتى النهاية.

### 2. نزّل المشروع على جهازك
افتح **موجه الأوامر** (Terminal على ماك، أو CMD/PowerShell على ويندوز) واكتب:

```bash
git clone https://github.com/fmagahwry5-commits/hoba-system22.git
cd hoba-system22
git checkout arena/019f7c33-hoba-system22
```

أو نزّله كملف مضغوط من GitHub وافتح مجلده في موجه الأوامر.

### 3. شغّل النظام

```bash
node server.js
```

> ✅ لا يحتاج `npm install` — لا توجد أي مكتبات خارجية.

ستظهر لك رسالة مثل:

```
✅ نظام هوبا يعمل الآن!
🖥️  من هذا الكمبيوتر افتح:   http://localhost:3000
📱 من الموبايل افتح:  👉  http://192.168.1.5:3000
```

افتح **http://localhost:3000** في المتصفح — النظام يعمل الآن على الكمبيوتر 🎉

---

## 📱 الربط بالموبايل

1. تأكد أن **الموبايل والكمبيوتر على نفس شبكة الواي فاي**.
2. خلّي `node server.js` شغّال على الكمبيوتر.
3. على الموبايل، افتح المتصفح (كروم/سفاري) واكتب العنوان الظاهر في الشاشة السوداء، مثال:
   ```
   http://192.168.1.5:3000
   ```
4. **لتثبيته كتطبيق على شاشة الموبايل:**
   - **أندرويد (كروم):** قائمة ⋮ ← «إضافة إلى الشاشة الرئيسية»
   - **آيفون (سفاري):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية»

> لو فتحت موجه الأوامر والعنوان غير ظاهر، اكتب `ipconfig` (ويندوز) أو `ifconfig` (ماك/لينكس) وابحث عن IPv4 مثل `192.168.x.x`.

### ⚠️ لو الموبايل لم يفتح الصفحة؟
- تأكد أن الجهازين على **نفس الواي فاي** فعلاً (ليس بيانات الهاتف).
- **جدار حماية ويندوز:** أول تشغيل سيسألك "السماح بالوصول للشبكة" — اضغط **سماح/Allow**.
  لو فاتتك الرسالة: افتح *Windows Defender Firewall ← السماح لتطبيق* واسمح لـ Node.js على الشبكة الخاصة.

## 💾 البيانات والنسخ الاحتياطي

- كل البيانات (منتجات، فواتير، عملاء، مصروفات) تتحفظ تلقائياً في ملف:
  ```
  data/db.json
  ```
- **نسخة احتياطية** = انسخ هذا الملف في مكان آمن، أو نزّلها من داخل النظام:
  **الإعدادات ← تنزيل نسخة احتياطية**.
- الملف `data/` مستبعد من GitHub عمداً — بياناتك تبقى على جهازك أنت.
